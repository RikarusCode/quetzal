Room

To play multiplayer, each player should start a game session and play past the first few interactions until the in-game menu is available. Then, one player should create a room, which everyone else can join. The host should then enable Multiplayer from the in-game menu, followed by the other players enabling it as well. Each player controls their own trainer and keeps their own progress. Rooms connect running games; they do not share or combine save files.
